Android Builder 1.0.1 — нусхаи насбшавандаи санҷишӣ ва коди ҳамон версия.

APK барои насб аст, ZIP барои нигоҳ доштани коди лоиҳа. Барои навсозии барнома ҳамон номи баста, калиди имзо ва рақами версияи афзоянда лозим аст. Калиди имзо дар ZIP нест. Ин APK бо бастаи ҷудогона ва имзои санҷишӣ сохта шудааст ва нашри асосӣ ё навсозии Personal нест.
Огоҳии навсозӣ дар код мавҷуд аст, вале ин нусха ба манбаи навсозиҳои зинда пайваст нест.
