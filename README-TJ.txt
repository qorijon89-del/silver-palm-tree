Android Builder 1.0.2
Ин нусха аз коди 1.0.1 коркард шуд: матнҳои барнома як забонро пайравӣ мекунанд; интихобҳои такрории файл аз саҳифаи асосӣ бардошта шуданд; майдонҳои лоиҳа барои клавиатура ислоҳ шуданд.
APK барои насб аст. ZIP барои нигоҳ доштани коди ҳамон версия аст. Ин APK бо бастаи ҷудогонаи санҷишӣ сохта шудааст; калиди хусусии барномаи пешина дар ZIP ё бойгонӣ нест. Барномаи пешинаро ҳазф накунед, агар дар он лоиҳа ё калиди муҳим доред.
Навсозии дохилӣ ба нашри имзошуда ва манбаи навсозии фаъол ниёз дорад. Агар навсозӣ воқеан дастрас набошад, Builder инро нишон медиҳад; агар манбаъ пайваст набошад, он хатои пайвастро ҷудо нишон медиҳад.
