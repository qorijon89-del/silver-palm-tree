# Android Builder (main project)
Application ID: tj.builder.app. This is a new production project identity; previous 0.x previews used different IDs and test signers. This repo never stores a real signing key or signing password.

The new project wizard covers name, package, visible version, automatic version increments after successful builds, requested permissions, optional icon, and output format. First-launch choices for Tajik, Russian, English and Persian are retained, and the wizard supports RTL. Legacy tool screens are still partly Tajik. The main app targets Android 16 (API 36) and its local HTML output template supports API 24 or later. It does not cap installation at Android 16.

Local HTML-to-APK export assigns the saved package and version to the output and reuses a separate Android Keystore signing key per app ID. Android Keystore entries are not exportable: uninstalling Builder or losing the phone may destroy those generated-project keys, so do not treat them as a cross-device backup. HTML to AAB remains unavailable. Native ZIP remote builds still return debug builds; production signing for them, the live service/AI, full language coverage, and the update distribution channel remain outstanding.

Build the unsigned main app with Gradle 8.11.1, JDK 17, SDK 36. Use the private signing script only after an owner-controlled, backed-up encrypted release keystore and private password storage are available. Pin the SHA-256 certificate fingerprint before signing. The workflow uses an ephemeral key only to check identity and continuity and never distributes it. Play App Signing is a separate release choice. No Play release is published by this repository.
