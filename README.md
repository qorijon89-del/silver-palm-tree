# Android Builder 0.2
Native Tajik UI: local HTML or HTML ZIP to signed test APK, optional PNG/JPEG icon, optional HTTPS network access in the generated HTML app, accessible status and save picker. Default output has no internet access. ZIP has index.html at top level. This preview has one fixed exported test package ID; its app-scoped export key is not for release signing. Builder 0.2 can sit alongside 0.1.
The Android ZIP picker checks project structure without uploading. The separately tested core scripts/build_native_zip.py compiles a standard app module from a trusted ZIP into debug APK/AAB with pre-warmed Gradle 8.9 and Android 35. It executes Gradle project code; route real builds only to disposable restricted workers without credentials. The example pipeline runs the native ZIP step without external network. No upload endpoint, Play release signing, AI mode or in-app updater is deployed.
